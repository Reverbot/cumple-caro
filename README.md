# 🌸 La tercera flor — Cumpleaños Caro

Página web interactiva para el cumpleaños de Caro (Linda Schiffmann), 30 de octubre de 2026.

## 📖 Descripción del Proyecto

- **Inicio:** A las 00:00 del 30 de octubre (hora de Bogotá).
- **Final interactivo ("La tercera flor"):** Se desbloquea únicamente al abrir el enlace del código QR de la tarjeta del ramo, sin apertura automática.
- **Estructura:**
  - Sobre interactivo con sello de cera.
  - Ilustración de luna interactiva y animaciones estelares.
  - Historia cronológica de tres flores y tres cumpleaños.
  - Galería de fotos, cartas y vales de regalo interactivos.
  - Soundtrack y reproductor de música integrado.

## 🚀 Estructura de Archivos

- `index.html`: Estructura principal, estilos y animaciones interactivas.
- `img/`: Fotografías y recuerdos.
- `audio/`: Pistas de música y audios de fondo.
- `js/`: Scripts interactivos (GSAP, ScrollTrigger, `soundtrack.js`, `config.js`).
- `resumen-cumple-caro.md`: Documentación detallada del proyecto y especificaciones.

## 💻 Vista previa local

Para correr localmente:

```bash
# Con Python
python -m http.server 8000
```

Abrir `http://localhost:8000` en el navegador.
